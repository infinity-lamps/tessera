01 · Install

Put the firmware on a new board

You only need this once per board. This page writes the bootloader, the firmware and the lamp's web interface straight from your browser over USB. After that, the lamp updates itself.

This browser cannot talk to USB devices. Open this page in Chrome, Edge, Opera or Brave on a desktop computer. Firefox, Safari and every browser on iPhone and iPad cannot do this.
This page has to be opened from its web address. A copy saved to your computer cannot reach USB devices.

Installs the latest release · Erases the board

Needs Chrome, Edge, Opera or Brave on a desktop computer. Firefox, Safari and every browser on iPhone and iPad cannot talk to USB devices, so the button will not appear there.

Before you start

  • Use a USB data cable. A charge-only cable is the most common reason the board never appears.
  • Plug into the ESP32-S3's own USB port, not a separate serial adapter.
  • No port listed? Hold BOOT, tap RESET, release BOOT, then try again.
  • On Windows, some boards need the CP210x or CH340 driver. Boards with native USB need neither.

After it finishes

  1. 01

    Join the lamp's network

    The lamp starts its own WiFi network called infinity-lamp. It is open, with no password.

  2. 02

    Open the lamp's page

    It usually opens by itself. If not, go to http://192.168.4.1/

  3. 03

    Connect it to your WiFi

    In the Network section, enter your WiFi details, save, then restart the lamp. It is then at http://infinity-lamp.local/

  4. 04

    Tell it what you built

    Under Advanced settings, set the shape, LEDs per edge and colour order. Nothing about the layout is built in, so a hardware change never needs a reinstall.

02 · Updates

Updates arrive on their own

Lamps on your WiFi check this site for new firmware. Each download is checked against its published checksum before it is installed, and your settings, palettes and custom effects carry across.

Check from the lamp

Open the lamp's page, then Advanced settings, Firmware and updates, Check for updates.

Stable or beta

Stable is for everyday use. Beta gets new features first and may have rough edges. A lamp set to stable never installs a beta.

No internet on the lamp?

Download the files from Releases and upload them under Firmware and updates. Settings are kept the same way.

Update address https://infinity-lamps.github.io/tessera/firmware/manifest.json The file every lamp reads. Its address does not change.
