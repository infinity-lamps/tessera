Infinity Lamp firmware installer

Flash a new ESP32-S3 straight from this page. No IDE, no toolchain, no command line.

This browser cannot talk to serial devices.
Open this page in Chrome, Edge, Opera or Brave on a desktop computer. Firefox, Safari and every browser on iOS lack the Web Serial API entirely. This page must be served over HTTPS. Use the published address rather than a local copy of the file.

Installing version .... This erases the board and writes the bootloader, partition table, firmware and web interface.

Before you start

  • A USB data cable. Charge-only cables carry no data and the board will never appear in the port list; if nothing shows up, this is almost always why.
  • Plug into the ESP32-S3's USB port, not a separate UART adapter, unless your board only has the latter.
  • If no port appears, hold BOOT, tap RESET, release BOOT and try again. That forces the download mode some boards do not enter on their own.
  • On Windows you may need the CP210x or CH340 USB-serial driver, depending on which chip your board uses. Native-USB S3 boards need neither.

After it finishes

  1. The lamp starts its own WiFi network called infinity-lamp. Join it from a phone or laptop - it is open by default.
  2. A sign-in page should appear automatically. If it does not, browse to http://infinity.lamp/ or http://192.168.4.1/.
  3. Open Advanced settings, enter your own WiFi details and reboot. The lamp is then at http://infinity-lamp.local/.
  4. Tell it what you have built - shape, LEDs per edge, colour order - under LED & shape config. Nothing about the lamp's layout is compiled in, so there is never a reason to reflash for a hardware change.

Later updates

You should not need this page again. Once the lamp is on your network, open its web interface, go to Advanced settings -> Firmware and updates and press Check for updates. The lamp downloads and verifies the new image itself, keeping every setting, palette and custom effect. Come back here only if a lamp is so thoroughly broken that its web interface no longer loads.
